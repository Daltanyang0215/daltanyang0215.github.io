아르 (Are)

제작·탐험 · PC · 데모 공개 · itch.io · 플레이 영상

시드로 만든 세계에서 재료를 모아 제작하는 게임으로, 이후 프로젝트로 이어진 기술을 처음 시도했습니다. 시드 기반 지형 생성, 3×3 칸에 재료를 놓는 조합 레시피, 그린 마법진의 모양을 판정하는 입력, 부품·재질 코드로 나눈 장비 데이터를 만들었습니다.

사례

수백 가지 조합 장비를 코드 하나로

데이터 1개 새 재료를 추가할 때 필요한 작업. 모든 부품·아이콘·3D 모델에 바로 적용
상황

장비의 부품 칸마다 재료를 골라 만드는 조합 제작입니다. 칸마다 재료를 고르고 다중 조합까지 되는 구조라, 만들 수 있는 장비가 수백 가지를 넘었습니다.

제약

조합마다 아이템 에셋, 아이콘, 3D 모델을 따로 만들 수는 없었습니다.

선택과 이유

장비 하나를 부품 코드와 재질 코드 두 정수로 표현했습니다. 칸마다 두 자리씩 담고, 나눗셈과 나머지로 꺼내 씁니다.

부품0103020504103020504
재질0202010301202010301

그림은 파츠별 리소스를 흰색으로 만들고, 재료별 색과 머티리얼을 입혀 파츠 우선순위대로 겹쳐 그립니다. 2D 아이콘과 3D 모델 모두 같은 방식입니다.

결과

새 재료는 재질 데이터 하나만 추가하면 모든 부품의 아이콘과 3D 모델에 바로 적용됐습니다.

한계

정수 하나에 두 자리씩 담는 방식이라 칸은 5개, 종류는 100개가 상한입니다. 정수 범위 때문에 첫 칸은 21번까지만 들어갑니다.

조합을 데이터로 나눠 표현한 경험은 이후 프로젝트의 데이터 주도 설계로 이어졌습니다.
