포트폴리오로
개인 프로젝트 · 2023.08 – 2023.09

PSY

미완성 · 기술 실험

염력 2D 액션 · PC · 비공개

염력으로 물체와 적을 잡고 던지는 2D 액션을 시험하던 프로젝트입니다. 게임으로 마무리하지는 못했고, 이 페이지는 그 안에서 만든 상호작용 구조만 다룹니다.

사례

입력과 출력을 허브 한 곳에서 잇기

상황

버튼을 누르면 문이 열리고, 버튼을 누르면 발판이 움직이는 것처럼 조작과 결과가 이어지는 장치가 많았습니다. 버튼 여러 개를 모두 눌러야 하나가 동작하는 경우도 있었고, 결과마다 누르는 대상을 모두 검사할 수는 없었습니다.

검토한 방법

입력이 출력을 알게 하거나, 출력이 입력을 알게 하는 방법을 생각했습니다.

  • 입력 하나 → 출력 여럿은 어느 쪽으로도 되지만, 입력 여럿 → 출력 하나는 구성이 맞지 않았습니다.
  • 두 방향을 모두 만들면 읽기 어렵고, 서로를 부르다 순환에 빠질 위험이 있었습니다.
선택과 이유

입력과 출력 사이에 허브를 두었습니다. 인스펙터에서 링크 데이터를 개수 제한 없이 만들고, 링크마다 입력 목록과 출력 목록을 넣습니다. 입력이 모두 켜지면 출력을 실행하고, 하나라도 꺼지면 취소합니다.

출력은 실행·취소 형식만 갖추면 붙기 때문에, 장치 종류가 늘어도 허브를 고치지 않습니다.

결과
  • 출력이 이동·타임라인·카메라 연출·시야 제한·횟수 검사로, 입력이 버튼·적 처치로 늘었습니다.
  • 퍼즐 몇 개와 특정 구역에 들어서면 보스가 나오는 이벤트를 같은 구조로 만들었습니다.
  • 연결은 씬에서 기즈모 선으로 바로 확인합니다.

나중에 이 구조가 중재자(Mediator) 패턴이라는 것을 알게 됐습니다.

한계
  • 매 프레임(LateUpdate) 모든 입력의 상태를 확인합니다. 입력이 바뀔 때 알리는 방식으로 바꿀 수 있습니다.
  • 순환 검사는 연결이 한곳에 모여 있어 쉬워졌지만, 구현하지는 않았습니다.
